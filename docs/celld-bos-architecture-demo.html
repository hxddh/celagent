1 定位:celagent 中 Celld 与 BOS 各司其职
交互层

celagent (TUI)

  • Pi 引擎完整界面:对话 / 工具 / 多模型
  • 每轮对话结束触发 turn_end 钩子
  • 双写:worker 缓存 + BOS 直写,不阻塞对话
  • 启动时从 BOS 恢复历史并注入上下文
运行时

Celld 双节点

  • 分布式 Durable Object 运行时(18090/18091)
  • worker SQLite:会话快速缓存(2s 超时,丢了可重建)
  • 自动启动 + 端口预检 + 残留所有权清理
  • 故障转移:单节点挂掉由另一节点接管
权威存储

BOS 对象存储

  • 权威源:sessions/<id>.json 完整落盘
  • CAS 乐观锁(ETag + If-Match):并发写不冲突
  • If-None-Match 首写保护:冷启动不覆盖
  • 节点全挂 / 换机器 / 本地数据丢失 → 都能找回
⚡ turn_end 双写 ⚡
一句话定位: Celld 是"快"——低延迟缓存与运行时; BOS 是"稳"——不依赖任何节点的权威持久层。
产品承诺 "会话永不丢" 由 BOS 兑现,不依赖 Celld 存活(下方第 3 节实测证明)。
