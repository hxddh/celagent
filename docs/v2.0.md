# celagent 2.0 — 实现合同与验证记录

> 版本 **`2.0.0`**。本文件是 2.0 的实现合同：保证什么、不保证什么、对象怎么排、怎么验证。
> 配套：`README.md`（用户视角）、`docs/architecture.md`（架构）、`HANDOFF.md`（接手）。

## 1. 目标

把执行者从客户端进程搬到 supervisor，把工作区从手动 tar 搬到增量检查点：

- 客户端 detach/断网，supervisor 继续执行；
- 工具结果后自动生成工作区检查点；
- supervisor 崩溃后由 watchdog 拉起，从 manifest/checkpoint 恢复；
- 未完成工具最多一个 `unknown`，不静默重放；
- 成本 stats 来自 Pi usage；
- 本地 interval trigger preview；
- 不把 2.0 绑在 celld beta 或容器实时迁移上。

## 3. Supervisor 合同

```text
celagent up <id> --cwd <dir> [--attach] [--restore]
  → tmux new-session -d -s celagent-<id> ... celagent __tui <id>
  → watchdog 记录 pid，每 2 秒检查 tmux session
celagent attach <id>  → tmux attach-session
celagent down <id>    → stop marker + kill watchdog + kill tmux
```

- tmux 只负责 PTY/多客户端；lease、journal、manifest、checkpoint 仍由 `__tui` 进程完成。
- `/quit` 或 `down`：flush outbox、最终检查点、release lease、写 stop marker。
- `kill -9`：stop marker 缺失；watchdog 重新拉起；新 TUI 同机死 pid 立即接管，epoch+1。
- 笔记本休眠时本地 compute 暂停；跨机使用 `up --restore`；celld 容器移动会停容器，只能 checkpoint/restore。

## 4. 工作区检查点

- 扫描工作区，忽略 `.git`/`node_modules`/`.venv`/`dist`/`build`/`.cache`/`target`/`vendor`/`.amp`。
- 文件 SHA-256 命名 blob；上一检查点的 hash 作为缓存；未变文件不重传。
- 单文件默认 128 MB，总工作区默认 1 GB；超限明确报错，不写半成品。
- checkpoint 元数据内容寻址；同内容复用同一 checkpoint；manifest CAS 指向最新。
- `--force` 恢复只清理 checkpoint 管理路径，保留 `.git`/`node_modules` 等 excluded 目录。
- 相对 symlink 可恢复；指向工作区外的 symlink 跳过并告警。
- 不保存进程内存、socket、数据库运行时；服务重启在 2.1 的 `.celagent/services.yaml`。

## 5. Lease

- owner = `<hostname>-<pid>`；TTL 15 秒；心跳 5 秒。
- 同机死 pid 立即接管；跨机等 TTL；epoch+1 fencing。
- `checkpointWorkspace` / manifest CAS 前 `lease.assert`；心跳覆盖长检查点。
- 第二个 `up` 明确报 `SessionLockedError`；不做并发多写。

## 6. Triggers（preview）

```text
~/.config/celagent/triggers/<id>.json
runTriggerDaemon：每 30 秒检查 dueTriggers；lastPid 存活则跳过
每次 run 使用新 session（trg-<id>-<timestamp>），不抢 TUI lease
```

- 只支持 `everyMinutes`；cron/webhook/预算硬停/审批/通知在 2.1。
- 触发器与 `run` 拥有相同工具权限；无人值守写操作应使用独立 worktree/cwd。

## 7. CLI

| 命令 | 说明 |
|---|---|
| `celagent` / `celagent <id>` | up + attach（2.0 默认；`--foreground` 保留旧进程内 TUI） |
| `celagent up/attach/down/ps/logs` | supervisor 生命周期 |
| `celagent run --prompt ...` | 无头运行 |
| `celagent status` | durable seq / lease / outbox / workspace / stats |
| `celagent workspace checkpoint/list/restore/status` | 增量工作区 |
| `celagent trigger add/list/rm/run/daemon` | 本地 interval trigger preview |
| `celagent list/export/rm/import-v0` | 会话管理 |
| `celagent doctor/cas-probe/config` | 自检/存储/配置 |

## 8. 验证记录（2026-11-14）

环境：Node 26.13.1，Pi 1.5.2，tmux 3.5a，celld 0.6.3 二进制，aws-cli 1.46.3，moto S3（本地，支持 If-Match/If-None-Match），本地 OpenAI-compatible mock provider。

$ npm audit --omit=dev

$ bun build bin/celagent-tui.mjs --compile --outfile celagent-linux-x64
[2129 modules] 116 MB；version/help/up/down 二进制冒烟通过

$ node bin/celagent-tui.mjs run --session e2e-6 --cwd /tmp/agent-ws --prompt "hello" --json

$ node bin/celagent-tui.mjs up e2e-sup2 --cwd /tmp/agent-ws
